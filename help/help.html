Clip It! - Extension Help

Save time and clip coupons automatically

Step 1: Login

Login to your account on any of the supported websites:

  • Kroger.com
  • KingSoopers.com
  • CityMarket.com
  • SmithsFoodAndDrug.com

Step 2: Navigate to Coupons

Navigate to the Savings > Digital Coupons page on any of the supported websites.

Step 3: Use the Extension

Click on the Clip It! extension icon and select an action:

  • Clip Coupons - Clips coupons up to your set maximum
  • Clip FREE Coupons - Only clips coupons marked as FREE
  • Unclip All - Removes all clipped coupons

Step 4: Configure Settings

To configure the maximum number of coupons to be clipped, adjust the Max coupons to clip slider to your desired number.

Tip: Setting a lower number (20-30) improves performance.

Common Issues & Solutions

Extension Not Working

  1. Refresh the page
  2. Disable and re-enable the extension
  3. Clear your browser cache

Slow Performance

If the extension is running slowly:

Tip: Configure the maximum number of coupons to a lower value (20-30) for better performance.

Not All Coupons Clipped

If not all coupons are being clipped:

  • Verify you're logged in to your account
  • Check if you've reached the maximum coupon limit (200)
  • Try running the extension again
